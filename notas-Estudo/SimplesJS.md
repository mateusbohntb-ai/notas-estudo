## variavel

``` js
-A variavel é um local onde arzenamos informações ou seja quando colocarmos a variavel em pratica ela vai armazenar a resposta do usuario
Ex:  
    const numero = Number(prompt("Digite um número:"))
    const outronumero = Number(prompt("Digite outro número:"))
    alert(numero + outronumero)
    
    -Aqui no primeiro const estamos pedindo um numero e  com o digito do usuario ele sera armazenado para ser ultilisado no alert.
    Obs: O number é se quisermos armazenar numeros 
```
